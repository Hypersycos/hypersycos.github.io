## Overview

This page describes three mods implemented using BepinEx and HarmonyX:
- [Arkshot-MultiplayerSync](https://github.com/Hypersycos/Arkshot-MultiplayerSync), a framework for networking mod configurations
- [Arkshot-StaminaPlus](https://github.com/Hypersycos/Arkshot-StaminaPlus), a mod which allows customisation of the stamina costs (and generation) of different actions and powerups
- [Arkshot-MorePlayers](https://github.com/Hypersycos/Arkshot-MorePlayers), which increases the maximum player count of a lobby beyond 4
